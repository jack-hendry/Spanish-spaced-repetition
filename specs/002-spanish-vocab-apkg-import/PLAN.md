# PLAN: 002-spanish-vocab-apkg-import

## Approach

The only code that changes is `tools/convert_apkg.py`. Today it maps note fields
by fixed positional index (`--front`/`--back`), grabs a single `[sound:...]`
from all joined fields into `SideAAudio`, and hardcodes `noteType:
"spanish2both"` plus a phrasal-verbs title. The core change is to make the
converter **model-aware**: read the collection's `col.models` JSON, build a
`mid -> {model name, field-name -> index}` map, and dispatch per note by model
name. Notes in the **"Spanish Vocabulary Practice"** model get mapped by field
name (8 fields); notes in any other model keep the existing simple
Front/Back/single-audio behaviour so the 550-phrasal-verbs path still works; the
stray **"Basic"** note is skipped with a one-line log.

For the Spanish model we emit `SideA` = Spanish text and `SideB` = English text,
each with the matching example sentence appended as context. The template
renderer (`web/.../template-renderer.ts`) substitutes field values into the card
HTML **unescaped** (`{{SideA}}` -> raw value), so we represent the sentence by
appending `<br>` + the sentence to the side text (e.g.
`"perro<br>El perro corre."`); this renders as a second line with no template or
note-type change. The two Spanish audio clips map to the two audio slots:
`Vocab Audio` -> `SideAAudio` (plays with the Spanish front), `Sentence Audio`
-> `SideBAudio` (plays on the answer). We emit `noteType: "spanish2"` (one card
per note, ~3638 cards). No English audio is synthesised.

Audio handling is refactored into one helper that, given a raw field value,
extracts the `[sound:name]`, resolves it via the media map, copies it into
`data/spanish/media/`, and returns a `/media/<name>` path (the only local form
`transform.ts` accepts) or `None`. A note whose audio can't be resolved is still
imported text-only, and the miss is counted and logged. Identity stays
`Card_ID = Anki note id` so `(bookSlug, Card_ID)` reconciles in place on
re-import.

## Tasks

**T001 — Read model definitions + note model id.**
Files: `tools/convert_apkg.py`. Change the notes query to
`SELECT id, mid, flds FROM notes ORDER BY id`. Add `load_models(conn)` reading
`SELECT models FROM col` (JSON blob), returning `{mid(str): {"name": str,
"fields": {field_name: index}}}` built from each model's `flds` (ordered by
`ord`). Keep it a standalone function taking a connection.
Done when: a scratchpad script that extracts the real apkg and calls
`load_models` prints a model named "Spanish Vocabulary Practice" whose field map
has `Spanish`->0 … `Sentence Audio`->7, and also lists a "Basic" model.

**T002 — Field mapping + example-sentence assembly for the Spanish model.**
Files: `tools/convert_apkg.py`. Add a builder that, given a note's split field
list and the model's field-name->index map, returns `(sideA_text, sideB_text,
vocab_audio_raw, sentence_audio_raw)`. All text `.strip()`-ed. `SideA` =
`Spanish`, with `Spanish Sentence` appended as `"<sideA><br><sentence>"` only
when non-empty; `SideB` = `English` + `English Sentence` the same way. Return the
raw `Vocab Audio` / `Sentence Audio` field values (audio copy happens in T003).
No card emitted if both Spanish and English are empty.
Done when: a scratchpad call on one real note returns trimmed Spanish/English
text with the sentence on a second line and both raw `[sound:...]` values.

**T003 — Dual-audio resolve-and-copy helper.**
Files: `tools/convert_apkg.py`. Refactor the existing sound logic into
`resolve_audio(raw_value, filename_to_number, tmp)` -> `/media/<name>` or `None`
(runs `SOUND_RE.search` on the single field value, resolves via media map,
copies to `MEDIA_DIR`, keeps the `"{number}-{slug}.mp3"` naming). Return a flag
so the caller can count copied vs. missing. Guard `None`/empty input.
Done when: a scratchpad call resolves a real `Vocab Audio` value to a
`/media/…mp3` path and the file exists under `data/spanish/media/`; an
unresolvable value returns `None` without raising.

**T004 — Model-dispatched main loop + counters + noteType `spanish2`.**
Files: `tools/convert_apkg.py`. In `convert()`, look up each note's model via
T001. For "Spanish Vocabulary Practice": use T002 + T003 to build the card with

log once (`[convert] skipping 1 Basic note`). For any other model: keep the
current positional Front/Back + single-audio path. Set the emitted book's
`noteType` to `"spanish2"`. Extend the summary print with matched-card count,
skipped count, media copied, and unresolved-audio count.
Done when: `python tools/convert_apkg.py <apkg>` runs end-to-end on the real
file and the summary reports ~3638 matched cards, 1 skipped Basic note, and a
nonzero copied count.

**T005 — Derive title/slug from the deck (drop phrasal-verbs default).**

  emitted filename/title.

- **Acceptance criteria 1–2** covered by T006; **AC 3** by T007 (import + app
  spot-check); **AC 4** (re-import reconciles, no dup/loss) by T007.

## Discovered / Open

- Example-sentence representation uses an inline `<br>` in the side text; this is
  confirmed safe because the renderer substitutes field values unescaped
  (`template-renderer.ts` `substituteFields`). If a build-time check shows
  escaping, fall back to a plain newline — note it in STATE, do not change the
  note-type template (out of scope).
- T005 assumes the apkg's embedded deck name is close to the target title; if it
  differs, use explicit `--title`/`--slug` flags to hit the required slug and
  record the embedded name in STATE. No scope change either way.
